# 0.1.3 实现与验证记录

基于 PR #1 的 `568ff54cd08d9763181b2016d40695d06ee5d1b0`，在本地分支
`fix/reliable-delivery-and-operations` 实现。原始评审副本未修改。

## 已实现

- 真实 InboundMessage 的 started/completed/ignored/uncertain 生命周期；进程中断后不自动重跑已开始任务。
- 禁止批处理，保留每条消息的 key 和所有者/管理员身份；单槽队列突发消息不丢失，明确拒绝入队可重试。
- 原版 gateway 使用逐次 worker 交接确认；确认发生在会话锁之前，避免阻塞 /stop。
- 群聊触发与历史条数独立，history_limit=0 仍遵守“仅回复 @”。
- 非所有者命令独立提示队列、正确私聊目标、不对未触发的群命令回复、不阻塞所有者消息。
- HTTP 连接复用、DNS 固定与私网策略、TLS/主机名校验、禁用环境代理、拒绝重定向、总截止时间与 Retry-After。
- 满页轮询立即追赶、事件排序推进游标、最多四个并行 ACK、退避与诊断。
- 只读状态、容量预警、独占锁保护的备份/归档、永久去重 key、明确确认后的 uncertain 重试、回滚旧版前恢复去重记录。
- 中英文权限边界说明、宿主入队回执与状态 API 补丁、Linux/macOS CI 配置、ZIP 宿主加载。
